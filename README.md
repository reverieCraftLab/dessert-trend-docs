# dessert-trend-docs

## AI 활용

이 문서는 Anthropic의 Claude(Sonnet 5.5)와 대화하며 작성하고 있습니다.

- 작성 방식: 요구사항의 내용과 결정은 작성자가 직접 정하고, Claude는 작성 순서 안내, 모호한 부분에 대한 질문, 문서 뼈대와 결정 기록 정리를 맡습니다.
- 기록: 판단 근거는 [docs/decisions.md](docs/decisions.md)에 남깁니다.

## AI 리뷰

작성자가 요구사항 기술서를 완성해 올린 뒤, Claude와 대화하며 정리한 최종 내용에 대한 리뷰와 평가를 이 아래에 추가할 예정입니다.
